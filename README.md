# ElTek – IT Solutions Website

Premium, responsive corporate website built with Next.js, Tailwind CSS, Framer Motion, and Lucide React.

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```
